# Homebrew package

The previous project's Cask is intentionally not distributed with CAD. Add a Spanvision Infra Cask after `repository_url` and `release_url` are configured in [brand.json](../../brand.json) and a macOS release artifact exists. The Cask should install `SpanvisionCAD.app` and use `com.spanvisioninfra.cad` for preference paths.
