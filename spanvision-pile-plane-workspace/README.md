# Pile Plane Workspace

**Spanvision infra · PPW · 0.4.2 Alpha**

Pile planning with the existing Rust engineering core, browser WASM adapter and Windows Tauri application. Import load points, CPTs and foundation advice; compare options, manage groups and assignments, optimize plans and save/reopen IFCPP projects.

Spanvision Mono provides grayscale controls and a lighter monochrome canvas. Existing themes, drawing colors, geometry and project data remain compatible. Responsive drawers and touch gestures extend the desktop workflow.

See [ARCHITECTURE.md](ARCHITECTURE.md) and [BUILDING-SPANVISION.md](BUILDING-SPANVISION.md). Pile preview uses port 4255; the suite hub remains on 4230.
