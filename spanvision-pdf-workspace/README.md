# geptechniek workspace · PDF

**Spanvision infra** · Windows PDF editing, drawing and measurement · GW monogram

This edition preserves the SolidJS interface, PDF editing engines, native Tauri/Rust backend, document formats and IPC commands. Spanvision Mono is the default for new installations. Saved themes, canvas colors and document colors remain independent.

## Local preview

Run from the application directory:

    cd open-pdf-studio
    npm ci --ignore-scripts
    npm run dev:preview

Open http://127.0.0.1:3084/preview.html for the landing, assistant suggestions, scan, login, sign-up and account previews. Open http://127.0.0.1:3084/ for the actual editor. The preview command bypasses native runtime preparation.

The editor can open, annotate, measure and save PDFs through browser file selection and downloads. The scan demonstration simulates processing. Real OCR, CAD import/export, native printing, digital signature verification and local MCP require the Windows app. Account forms are explicitly labeled prototypes; they do not send or store credentials and no cloud accounts are created.

## Windows development and packaging

Requirements: Node.js 22 or newer, Rust stable with the MSVC toolchain, Visual Studio Build Tools with Desktop development with C++, a Windows SDK, and WebView2. Required native DLLs and resources from the supplied archive are retained. The existing preparation scripts fetch OCR data and build the PDFium sidecar.

    cd open-pdf-studio
    npm ci --ignore-scripts
    npm run tauri:dev
    npm run tauri:build

The application identity is com.spanvisioninfra.pdfworkspace; the executable is SpanvisionPDFWorkspace.exe. NSIS uses the GW icons and Spanvision PDF Printer. Release workflows are manual and disabled unless the repository variable SPANVISION_RELEASES_ENABLED is explicitly set to true. No public site deployment or upstream issue-assignment workflow is active.

## Edition configuration

brand.json is the shared identity and endpoint configuration. Frontend code reads it through js/core/brand.js; Rust constants are generated by build.rs. npm run check:brand checks manifests against it. Updater, hosted accounts, feedback, remote release information and online symbol downloads are disabled without configured edition services. Bundled symbols, imported symbols and user-configured assistant providers remain available.

Settings and assets use SpanvisionPDFWorkspace and com.spanvisioninfra.pdfworkspace. On first use, legacy data is copied only when the destination is empty; original data and newer edition settings are preserved. SPANVISION_PDF_DATA_DIR redirects local native app storage for testing; the previous OPDS_DATA_DIR alias remains compatible.

## Validation

    npm run typecheck
    npm run test:unit
    npm run test:quality
    npm run test:edition
    npm run build:preview
    npm run test:preview
    node scripts/production-smoke.mjs

Browser QA uses Playwright with Microsoft Edge and saves screenshots and a JSON report in qa/. Start the preview server before running it. It checks 390px, 768px and 1440px layouts, scan focus/processing, prototype validation, the mounted document on resize, editing, undo/redo, save/reopen and saved preferences. Native migration tests are in src-tauri/src/storage_migration.rs. See docs/VALIDATION.md for this machine's verified results and outstanding native checks.
