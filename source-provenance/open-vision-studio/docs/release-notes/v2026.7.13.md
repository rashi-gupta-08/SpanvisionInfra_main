- AI assistant: an MCP server is now built into the app, so an AI client such as Claude Code can read and edit your planning directly. Turn it on in the new AI tab, with pause, read-only and automatic backups as safeguards.
- Resource libraries: share one resource pool across projects. The library is the source, the project shows what it actually uses, and deviations are marked so you can resolve them.
- Gantt and table: drag a whole selection vertically, collapse non-working days out of the timeline, week numbers in the header, Ctrl+click multi-select, and the WBS table now edits like a spreadsheet.
- Reports: adjustable font size, repeat the header on every page, spread the timeline over several pages, and every report setting is remembered. Interface font and text size are configurable as well.
- Fixes: dates could shift a day in some timezones; an apostrophe or semicolon in a task name could corrupt a saved file; crash recovery could lose dependencies or baselines; exports could ship a stale schedule; failed saves are no longer silent. One leftover needs your hand: files saved by an earlier version may show a literal "$" in a task description, WBS code or calendar description — that has to be cleared manually, as it can't be told apart from a "$" you typed on purpose.
- Manual: the in-app help is now available in all 14 languages, with new guides for resource libraries and for connecting an AI assistant.
