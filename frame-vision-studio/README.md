# Frame Vision Studio v0.6.0

Frame design, visualization and production workspace by **Spanvision infra**.

This modified open-source distribution provides a Spanvision Mono interface, new SV identity, accessible dialogs and controls, responsive panels, and branded PDF/IFC/glTF document identity. It preserves the original frame model, `.ofs` format, engineering drawing colors, typography, templates and desktop workflows.

## Run the preview

Requires Node.js 20 or later. From `ui`:

```sh
npm ci
npm run dev
```

Open the Vite address displayed in the terminal (normally `http://localhost:5173`). The compiled browser drawing engine is included. New installations use Spanvision Mono and English; existing theme/language/panel choices remain available. Settings → Theme includes all prior themes.

Companion screens: `/companion/index.html`, `/companion/workshop.html` and `/companion/ar-preview.html`. The workshop scan is the original simulation; AR requires a model URL and a compatible browser/device.

## Build

```sh
cd ui
npm run build
npm run preview
```

The complete static site is written to `ui/dist`, including fonts, brand assets, companion pages, browser engine and open-source notices. Serve this folder with an HTTP server; opening index.html directly from disk does not support the module/engine URLs.

For a local rebuild of the engine, install Rust, the wasm32-unknown-unknown target and wasm-pack, then run `npm run build:web` from `ui`. `scripts/build-wasm.mjs` supports Windows, macOS and Linux. The included upstream engine's exact origin and hashes are in `ui/public/wasm/PROVENANCE.json`; document references generated by that preserved engine are branded by the frontend adapter.

Native Tauri builds require the existing Rust/Tauri platform prerequisites and CLI. The desktop product/executable, package identifier and icons use the new branding. On first launch with the new desktop identifier, the app copies prior settings when they exist in the upstream configuration directory. Engineering crates and API command names retain their compatible identifiers.

## Scope and verification

- Existing frame, curtain-wall, profile and 3D workflows; reports and production views; AI suggestions/configuration; welcome and settings/About; three browser companion pages.
- Mobile/tablet drawers preserve saved desktop panel sizes and open states. The frame canvas has touch zoom/pan and Fit controls; wide tables and ribbons scroll within their own regions.
- Login, sign-up and account screens are absent from the supplied project and were not added. No business photography was present in the archive.
- Browser mode retains upstream limitations: some curtain-wall, file export/import, CNC and project-management features require the desktop runtime. AI requests require a configured provider. The rebrand does not add authentication or cloud persistence.

Architecture: `docs/spanvision-architecture.md`. Validation: `docs/spanvision-validation.md`.
