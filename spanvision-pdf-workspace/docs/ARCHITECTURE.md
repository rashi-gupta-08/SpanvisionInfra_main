# Spanvision infra — pdf workspace architecture

The edition is isolated in spanvision-pdf-workspace. The supplied source archive is unchanged. Internal engine crate names, IPC commands and PDF metadata keys remain compatible; the application package, executable, installer, printer and public UI have the new identity.

## Layers

1. **Edition identity** — root brand.json, frontend js/core/brand.js, Rust src/brand.rs generated by build.rs. JavaScript and Rust builds validate the application manifests. No upstream service destinations are inherited.
2. **Interface** — existing SolidJS components, ribbon and panels. styles/themes.css supplies Spanvision Mono tokens; mono-components.css adapts inherited literal chrome colors; edition.css provides focus states and responsive overrides. Document drawing, image and annotation colors stay in the rendering engine.
3. **Browser presentation** — preview.html and preview/main.jsx provide navigable local prototypes using the shared brand and Dialog component. index.html remains the actual editor. Vite builds both entries; dev:preview skips native build preparation.
4. **Platform boundary** — existing js/core/platform.js and webfuncties.js retain browser fallbacks and label native-only commands. The editor remains mounted when responsive CSS hides or overlays panels. Native commands and document schemas are preserved.
5. **Windows backend** — Tauri/Rust retains PDFium, PDF rendering, OCR, CAD, printing, signatures, plugins and local MCP. The native application identifier is com.spanvisioninfra.pdfworkspace and binary is SpanvisionPDFWorkspace.
6. **Data and templates** — migration copies legacy preference/user-asset directories into empty branded destinations through staging, preserving source data. Branded bundled templates retain their page boxes, scale viewports and title-block field identifiers. Customer PDFs are loaded unchanged.

## Responsive behavior

At 1024px and above the existing desktop panel arrangement is retained. Between 768px and 1023px, pages and properties become explicit overlay toggles. Below 768px, controls, ribbons, title bar and status bar compact and scroll locally. Resizing never replaces the document or canvas. Zoom remains a user-controlled document view setting.

## Hosted services

Login, sign-up, account and OCR browser screens are clearly labeled demonstrations. No credentials are transmitted. Native accounts and updates are disabled in brand.json. Local MCP and user-provided assistant connections remain operational. Publishing, hosted accounts and scanner hardware integration are outside this edition.
