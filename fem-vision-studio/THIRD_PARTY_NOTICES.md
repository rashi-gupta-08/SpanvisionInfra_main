# Open-source attribution

FEM Vision Studio is a Spanvision Infra branded adaptation of Open FEM2D Studio
from OpenAEC Foundation. The upstream project and vendored style packages retain
their original authorship and license notices.

Upstream: https://github.com/OpenAEC-Foundation

The supplied `LICENSE.md` contains LGPL v3 and GPL v3 license texts. Upstream
package metadata also declares CC BY-SA 4.0. Those original notices are preserved;
this adaptation does not replace or resolve the upstream license declarations.

Branding, theme integration and responsive interface changes in this distribution
identify the Spanvision Infra adaptation. Third-party libraries remain under their
respective licenses. Dependency names are retained for compatibility.
