- Gantt dependencies: finish-to-finish and start-to-finish arrows were drawn from the wrong edge of the successor — they now anchor correctly, on screen and in reports. Relation lines also route around task bars instead of disappearing underneath them.
- Split view and navigation: each pane now has its own scrollbar and mini-map, there is a real vertical scrollbar for large task lists, and Collapse/Expand are separate actions that work on the whole selection (or the whole plan). The task right-click menu got the same split, and "expand all / collapse all" now works in grouped views.
- Right-hand rail: the resource dock and the task properties panel now sit open side by side in one resizable rail, instead of one replacing the other.
- Resources: adding one opens an inline editable row that no longer jumps away after you type, with full keyboard navigation (Enter / Shift+Enter to move and to add another).
- Shortcuts and bars: Ctrl+Shift+H toggles the resource histogram, and the duration pill now updates live while you drag a bar edge.
- Packaging: Snap builds now publish to the Snap Store automatically on each release, and every written IFC file plus the bundled examples and demo library are now in English.
