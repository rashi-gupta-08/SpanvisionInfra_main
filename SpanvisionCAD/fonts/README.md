# CAD by Spanvision Infra: SHX fonts

When a DWG or DXF drawing references a missing `.shx` font, CAD can offer an
optional download from a font server selected by the user. No default external
source is configured in `brand.json`. Enter your organization's font folder URL
in the missing-font prompt to enable the download action.

Downloaded fonts are stored under `Spanvision Infra/CAD/fonts` in the
platform's application config directory. On first launch, eligible fonts from
the old `OpenCADStudio/fonts` profile are copied without deleting the source.

Only include fonts that you have the right to redistribute. Keep the original
filename so existing drawing references resolve, and record the font's source
and license below.
